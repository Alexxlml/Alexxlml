### Sobre mí

Desarrollo sitios y sistemas web desde 2022: sitios corporativos en HubSpot CMS y WordPress a partir del diseño y la marca de cada cliente, sistemas internos en Laravel y administración de servidores.

Lo que más disfruto es la arquitectura: decidir qué conviene usar y cómo diseñar algo para que crezca. Trabajo con IA para validar ideas y acelerar la ejecución sin soltar el control técnico. Así he llevado proyectos en Rust y C que diseño y dirijo yo.
